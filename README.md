# Proposta · Zeh Motoca

Landing de venda do sistema para a **Zeh Motoca Fortaleza** (@zehmotocafortaleza), com foco nas integrações: SafeLock, rastreamento, DETRAN, banco e VozChat.

No ar: https://pedcastr.github.io/proposta-zehmotoca/

| Arquivo | Para que serve |
|---|---|
| `index.html` | A página inteira, com as telas animadas feitas em HTML |
| `og-image.png` | Arte de preview ao compartilhar o link (1200×630) |
| `img/arte-whatsapp.png` | Arte quadrada (1080×1080) para redes sociais |

Os nomes e valores das telas animadas são de demonstração.
